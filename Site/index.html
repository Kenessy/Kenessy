Assignment Operator Expected

ERROR: draw_text(..., + string(button_text));
The logic failure was mine (sorry!), but the syntax error is caused by a stray + sign in your Draw Value block.

1. The Stray Plus Sign

❌ Your Code Snippet: draw_text(x + 0, y + 0, + string(button_text));

This + is illegal syntax here. It typically happens if you accidentally typed it into the Caption or Value field.

2. Target Lock: Draw Value Block

  1. Open Draw Event → Scroll to the bottom.
  2. Open the Draw Value block.
  3. Check Caption Field: Ensure it is empty.
  4. Check Value Field: Ensure it is ONLY button_text.
