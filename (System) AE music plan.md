# Apocalypse Express – Canto I Music Suite  
### v4 – Suno-Ready (Lyrics, Style & Exclude)

This note is the **Suno-ready** version of the Canto I music suite for *Apocalypse Express*.

For each track you get:

- **Overview entry** (ID, category, intensity, length).  
- A short **what/why** description.  
- A **Suno Lyrics** block (what to put in the Lyrics field).  
- A **Suno Style** block (for the Style / Description field).  
- A **Suno Exclude Styles** block (for the Exclude field).  

Instrumental and ambient tracks simply tell you how to mark them in Suno (usually leaving Lyrics blank or using an `[Instrumental]` tag).  
Vocal / diegetic songs have full, structured lyrics ready to paste.
