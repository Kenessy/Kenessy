# Horizon Zero Dawn — Session Entries

Create one file per substantial play session when the master `session-log.md` entry needs more room.

Naming:

```text
hzd-s01-YYYY-MM-DD-short-stop-label.md
hzd-s02-YYYY-MM-DD-short-stop-label.md
```

Every session file must contain:

- opening and closing timestamps in Europe/Budapest;
- starting and ending save/location state;
- difficulty and any changes;
- raw intake IDs;
- short chronological checkpoint list;
- confirmed observations separated from hypotheses;
- screenshot IDs;
- friction and recovery notes;
- next safe resume point;
- whether the session was synced remotely.

Never delete an earlier session entry to replace it with a cleaner narrative. Corrections are additive.
