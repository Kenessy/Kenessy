## Core public hook draft

I did not start **The Invincible** looking for a reflex test, a build system, or a game that would ask for more optimization after a programming day. I started it as a quiet hard-sci-fi field walk: a planet, a missing crew, analogue tools, and the question of whether slow mystery can still feel like agency. The review will track that tension honestly: when the game rests the brain, when it merely slows it down, and when its choices feel like real decisions rather than decorative branch labels.

## Before/after conversion rules

Raw Daniel line:

```text
[keep exact wording in raw-capture]
```

Processed public line:

```text
[rewrite into clear, readable, spoiler-labeled playthrough prose]
```

Do:

- preserve the real feeling of the session;
- compress rambling into one sharp observation;
- remove accidental spoilers from spoiler-light sections;
- keep friction visible;
- connect screenshots to evidence, not decoration.

Do not:

- invent emotions Daniel did not report;
- turn a boring session into false hype;
- hide fatigue or confusion;
- quote long copyrighted dialogue;
- score the game before evidence stabilizes.
